# Smart Closet

An AI-powered personal stylist app. Photograph your wardrobe, get outfit suggestions based on weather and occasion, and save looks you love.

## Stack
- React Native (Expo)
- FastAPI (Python)
- OpenAI GPT-4o (vision tagging + outfit generation)
- Supabase (database + image storage)
